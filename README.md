# Arunachal Dam Watch

A single-page dashboard of hydropower projects in Arunachal Pradesh: capacity, forest land, build time and cost, and reported incidents and their impact.

All data is built into `index.html`, compiled from government records (CEA, PIB, CERC, MoEFCC clearance papers) and news reports up to 1 November 2026. Every figure links back to its source in the Sources section at the bottom of the page.

Impact figures cover only what was reported, so treat them as a minimum.

## View it

Open `index.html` in a browser, or publish it with GitHub Pages:

1. Settings → Pages
2. Source: "Deploy from a branch", branch `main`, folder `/ (root)`
3. Save. The site appears at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
